2. CONNEXION AUX DONNEES CSV
============================================================

METHODE A - Import individuel (recommandee pour le prototype):
--------------------------------------------------------------
Pour chaque fichier CSV :

1. Dans Power BI Desktop : Accueil > Obtenir des donnees > Texte/CSV
2. Naviguer vers le dossier /PowerBI/ et selectionner le fichier
3. Dans la fenetre de preview :
   - Origine du fichier : 65001 (Unicode UTF-8)
   - Separateur : Point-virgule (;)
   - Detection du type de donnees : Premiere ligne
4. Cliquer "Charger" (ou "Transformer les donnees" pour verifier)
5. Repeter pour chaque fichier

METHODE B - Import depuis dossier (si tous les CSV sont au meme endroit):
-------------------------------------------------------------------------
1. Accueil > Obtenir des donnees > Dossier
2. Selectionner le dossier /PowerBI/
3. Dans Power Query, filtrer uniquement les fichiers PBI_*.csv
4. Combiner les fichiers individuellement (ne pas combiner en une seule table)

REGLAGE ENCODAGE DANS POWER QUERY (si accents incorrects):
-----------------------------------------------------------
1. Accueil > Transformer les donnees
2. Dans Power Query, cliquer sur la source de donnees
3. Dans la barre de formule, localiser :
   File.Contents("...")
4. Ajouter : Csv.Document(... [Delimiter=";", Encoding=65001])
   65001 = UTF-8

3. MODELE DE DONNEES (RELATIONS)
============================================================

Tables de faits:
  - PBI_Forecast      (faits de prevision)
  - PBI_DemandPlan    (faits plan demande)
  - PBI_CapacityPlan  (faits capacite)
  - PBI_InventoryPlan (faits stocks)
  - PBI_GapAnalysis   (faits ecarts)
  - PBI_Scenarios     (faits scenarios)
  - PBI_PlanFinal     (faits plan valide)
  - PBI_KPI           (faits indicateurs)
  - PBI_Alertes       (faits alertes)

Tables de dimensions:
  - PBI_Product       (dim produits / SKU)
  - PBI_Plant         (dim usines)

RELATIONS A CREER (dans Vue Modele > Gerer les relations):

Fact -> Dim:
  PBI_Forecast.SKU_ID        -> PBI_Product.SKU_ID   (N:1, Actif)
  PBI_DemandPlan.SKU_ID      -> PBI_Product.SKU_ID   (N:1, Actif)
  PBI_InventoryPlan.SKU_ID   -> PBI_Product.SKU_ID   (N:1, Actif)
  PBI_PlanFinal.SKU_ID       -> PBI_Product.SKU_ID   (N:1, Actif)
  PBI_CapacityPlan.Plant_ID  -> PBI_Plant.Plant_ID   (N:1, Actif)
  PBI_GapAnalysis.Plant_ID   -> PBI_Plant.Plant_ID   (N:1, Actif)
  PBI_PlanFinal.Plant_ID     -> PBI_Plant.Plant_ID   (N:1, Actif)

NOTE: Les colonnes Mois et Periode sont au format "aaaa-mm-dd".
Creer une table Date si vous souhaitez des filtres temporels avances.

4. MESURES DAX RECOMMANDEES
============================================================

-- Taux de service global (%)
Taux_Service = 
DIVIDE(
    SUMX(PBI_DemandPlan, [Qte_finale]) - SUMX(FILTER(PBI_InventoryPlan, [Statut] = "RUPTURE"), [Livraisons]),
    SUMX(PBI_DemandPlan, [Qte_finale]),
    0
) * 100

-- WAPE moyen (%)
WAPE_Moyen = 
AVERAGEX(FILTER(PBI_Forecast, [Statut] = "RETENUE"), [WAPE_pct])

-- Utilisation max capacite
Util_Max_Cap = MAXX(PBI_CapacityPlan, [Utilisation_pct])

-- Nombre de ruptures
Nb_Ruptures = COUNTROWS(FILTER(PBI_InventoryPlan, [Statut] = "RUPTURE"))

-- Nombre d'alertes critiques
Nb_Alertes_Critiques = COUNTROWS(FILTER(PBI_Alertes, [Criticite] = "CRITIQUE"))

-- Cout scenario recommande (SC-04)
Cout_SC04 = CALCULATE(MAX(PBI_Scenarios[Cout_total]), PBI_Scenarios[Scenario_ID] = "SC-04")

-- Demande totale horizon
Demande_Totale = SUM(PBI_DemandPlan[Qte_finale])

PAGE 1 - TABLEAU DE BORD EXECUTIF

[Carte KPI] Taux de service : Mesure Taux_Service | Cible: 95%

[Carte] Scenario valide dans PLAN_FINAL
[Histogramme] Plan de production par usine/mois

6. RAFRAICHISSEMENT DES DONNEES
============================================================

PROCEDURE DE MISE A JOUR DU RAPPORT:

1. Dans l'outil Excel, executer le cycle S.O.P. complet
2. Cliquer sur "Exporter vers Power BI" et choisir le dossier /PowerBI/
3. Dans Power BI Desktop, cliquer sur "Actualiser" (ruban Accueil)
4. Toutes les visualisations se mettent a jour automatiquement

RAFRAICHISSEMENT AUTOMATIQUE (Power BI Service):
Si le rapport est publie sur Power BI Service (cloud) :
- Configurer une passerelle de donnees (Data Gateway) sur le PC
  contenant les fichiers CSV
- Planifier le rafraichissement (ex: chaque lundi matin)
- Les utilisateurs voient toujours les donnees du dernier cycle

PARAMETRISATION DU CHEMIN DES FICHIERS:
Pour que le rapport soit portable (portable entre PCs) :
1. Dans Power Query : Accueil > Gerer les parametres > Nouveau parametre
2. Creer un parametre "DossierPowerBI" de type Chemin de dossier
3. Remplacer le chemin en dur dans les sources par ce parametre
4. Les utilisateurs peuvent changer le chemin sans modifier les requetes
